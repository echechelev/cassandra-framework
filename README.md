### 🌌 О проекте: Философия и концепция

**Cassandra** — это «Протокол априорной оценки планетарных систем», инициатива сообщества Evknopia Labs. Название отсылает к мифической Кассандре, чей дар предвидения позволяет заранее выявлять риски и факторы, делающие среду непригодной для колонизации.

В метафорическом смысле этот проект воплощает главную философию QA: качество закладывается на этапе проектирования, а надежная система должна уметь «предвидеть» сбои до того, как они станут критическими. Мы не просто ищем баги, мы оцениваем жизнеспособность системы в целом.

---

### 🏗️ Инженерная реализация (QA-инфраструктура)

На техническом уровне Cassandra представляет собой масштабируемый фреймворк автоматизированного тестирования, разработанный с нуля. Проект демонстрирует полный цикл QA-инженерии: от системного анализа и проектирования архитектуры до реализации 235+ стабильных автотестов, покрывающих 11 функциональных модулей.

Это живое доказательство того, что надежная QA-инфраструктура может быть выстроена самостоятельно, без готовых шаблонов, с глубоким пониманием паттернов проектирования и принципов поддерживаемости кода.

---

### 🛡️ Безопасность и архитектура данных

Проект реализован как frontend-only демо-стенд (без выделенного бэкенда и БД). В связи с этим учетные данные хранятся на стороне клиента.

**Ключевые моменты:**

* **Только тестовые данные:** Проект использует исключительно синтетические (демо) данные. В репозитории и приложении полностью отсутствуют реальные персональные данные (PII), платежная информация или любые конфиденциальные сведения.
* **Осознанный компромисс:** Данный подход недопустим для продакшена. Он будет заменен на полноценную серверную авторизацию при реализации бэкенда (запланировано в Roadmap на 2027 год).
* **Цель проекта:** Демонстрация навыков построения QA-архитектуры, паттернов и автоматизации UI.

### 📊 Масштаб проекта

- **235 автотестов** с покрытием критических бизнес-сценариев
- **11 функциональных модулей**: авторизация, регистрация, восстановление доступа, индекс, дашборд, карта галактики, информация о звездах, звездная система, информация о планетах, калькулятор времени полета,  расчеты индексов cis,

- **Allure Report** с детальной визуализацией каждого шага и шагов валидации

### 🚀 Архитектурные особенности

### 🏛️ Page Object Model (POM)
- Модульная структура с четким разделением ответственности
- Fluent interface (`return self`) для читаемых цепочек вызовов
- Централизованное хранение локаторов через кастомные атрибуты `data-wm-id`
- Встроенная обработка исключений и умные ожидания (waits)

### 🧪 Тестовая архитектура
- **Строгий паттерн AAA** (Arrange-Act-Assert)
- **Параметризация тестов** через мощные pytest fixtures
- **Изоляция тестов** через независимые фикстуры и моки
- **Data-driven подход** с вынесенными тестовыми данными (`users.json`, `data.py`)

### ⚙️ Инфраструктура и Code Quality
- **Pre-commit hooks** (`flake8`, `black`, `isort`) для автоматического контроля стиля
- **Конфигурация через `pyproject.toml`** и `pytest.ini`
- **Allure integration** для детальной и красивой отчетности
- **Гибкая конфигурация** через переменные окружения (`BASE_URL`)

### 🛡️ Quality Assurance акценты
- **Реактивная валидация** форм в реальном времени
- **Тестирование UX/UI состояний** (анимации, сетевые задержки, переходы)
- **Security testing** (валидация ввода, XSS payloads, защита от перебора)
- **Edge cases & boundary values** покрытие

###  Технологический стек

### 🤖 Automation & Backend
- **Python 3.11+** — основной язык разработки
- **pytest** — мощный и гибкий тестовый раннер
- **selene** — современная, лаконичная обёртка над Selenium
- **allure-pytest** — профессиональная система отчётности

### 🧹 Code Quality
- **black** — бескомпромиссное форматирование кода
- **isort** — интеллектуальная сортировка импортов
- **flake8** — строгий линтинг
- **pre-commit** — автоматизация проверок перед коммитом

### 🎨 Frontend (в тестируемом приложении)
- **HTML5, CSS3, JavaScript (ES6+)**
- **Vanilla JS** — без тяжёлых фреймворков для максимальной производительности

### 🌐 Infrastructure
- **GitHub Pages** — хостинг приложения
- **Git** — контроль версий
- **JSON** — хранение тестовых данных
