# 🚀 Cassandra Framework
## Техническое задание: Страница Galaxy Map (Карта Галактики)

### 📌 Обозначения

-   **`ElementName`** *(type)* — UI-элемент с указанием типа
-   *"Text content"* — отображаемый текст на интерфейсе
-   `code` — технические термины, классы, методы
- `'/galaxy-map.html'` *(url)* — адрес страницы (URL) для проверки навигации
-   ⚠️ *(decorative)* — декоративный элемент, не подлежит автоматизированному тестированию

## 1. 🎯 Назначение
Страница Galaxy Map — основной навигационный хаб системы после успешной авторизации. Обеспечивает визуальное представление доступных для исследования звёздных систем, отображает статус пользователя и его роль, а также предоставляет точки перехода к детальному просмотру систем, чёрной дыре, дашборду и таблице индексов.

## 2. 🖥️ Элементы интерфейса

### 2.1 Основные элементы формы

- **`Black Hole Link`** (link) — Центральный интерактивный элемент (Чёрная дыра). Ссылка ведет на black-hole.html. Внутри горизонта событий содержит текст Sagittarius A*. Состояние: Активна. При наведении (:hover) визуальные эффекты не изменяются, элемент просто кликабелен.

- **`Star Buttons`** (button) — Группа из 6 кнопок звёздных систем, расположенных в ряд под центральной дырой. Состояние: Активны. При наведении (:hover) увеличиваются (scale(1.15)), усиливается неоновое свечение.

    - `Sun Button` -  (Солнце)

    - `Alpha Centauri Button` - (Альфа Центавра)

    - `Epsilon Eridani Button` - (Эпсилон Эридана)

    - `Tau Ceti Button` - (Тау Кита)

    - `Teegarden's Star Button` - (Звезда Тегардена)

    - `TRAPPIST-1 Button` - (TRAPPIST-1)

- **`Dashboard Button`** (button/link) — Кнопка возврата на главный дашборд (нижний левый угол). Иконка: 🕹️.

- **`CIS Index Table Button`** (button/link) — Кнопка перехода к таблице индексов (нижний правый угол). Иконка: 🧬.

- **`Info Panel Role`** (container) — Информационная панель роли пользователя (верхний левый угол). Содержит иконку, название роли и тултип с деталями.

- **`Info Panel User`** (container) — Информационная панель данных пользователя (верхний правый угол). Содержит иконку, имя и тултип с позывным и ID.

- **`System Telemetry`** (text) — Строка телеметрии в футере, отображающая текущий статус системы и подсказки.

- **`Copyright Text`** (text) — Текст Evknopia © 2026 в самом низу футера.

- **`Galaxy Title`** *(text)* — Заголовок в верхней части экрана. Состоит из двух частей:

    - **`Title White Part`** *(text)* — Белая часть: `GALAXY`.

    - **`Title Blue Part`** *(text)* — Синяя часть: `MILKY WAY`.

### 2.2 Декоративные элементы ⚠️

> Примечание: Элементы данного раздела являются частью визуального оформления страницы и не подлежат автоматизированному тестированию. Они не имеют `data-wm-id` и не включаются в CAS-сценарии.

- **`Stars Background`** *(decorative/css)* — Анимированный фон со звёздами и Млечным Путём `.stars`, `.milkyway`.

- **`Milky Way Band`** *(decorative/css)* — Светящаяся полоса Млечного Пути .`milkyway .band`.

### 2.3 Служебные элементы

-   **`Telemetry`** *(text)* — Строка состояния системы в футере. Отображается моноширинным шрифтом с мигающим курсором (`█`). 

    -   Состояние по умолчанию (до авторизации): *"> SELECT A STAR SYSTEM FOR INVESTIGATION"* (синий цвет, rgb(77, 166, 255) / #4da6ff).

## 3. ✅ Правила состояний (State Rules)

- **`Состояние default:`** - Все элементы видимы. Кнопки имеют базовое неоновое свечение и cursor: pointer. Информационные панели имеют cursor: default.

- **`Состояние hover`** (для кнопок) - Усиленный box-shadow (внешний и внутренний), плавное увеличение масштаба (transform: scale(1.15)).

- **`Состояние active`** (при нажатии): Лёгкий эффект "проваливания" (transform: scale(0.95)).

## 4. ⚙️ Логика работы

> ⚠️ **Важно: Контекст проекта**
> Данный проект является учебным и **не имеет серверной части (бэкенда)**. 
> Все процессы аутентификации, хранения пользователей и передачи данных эмулируются исключительно на стороне клиента (Frontend) с использованием `sessionStorage` (для хранения активной сессии currentUser), `localStorage` (для эмуляции базы данных `registeredUsers`) и локальных конфигурационных файлов (data.js).
> В реальном продакшн-проекте эти функции выполнялись бы на сервере.

- Если сессия отсутствует или содержит невалидный JSON: Происходит мгновенный редирект на login.html.

- **`Навигация`**:

    - `Клик по Black Hole Link` → переход на `black-hole.html`.

    - `Клик по любой Star Button` → переход на `star-system.html?star={star_key}`.

    - `Клик по Dashboard Button` → переход на `dashboard.html`.

    - `Клик по CIS Index Table Button` → переход на `cis-index-table.html`.

## 5. 🤖 Спецификация данных

Данные для панелей берутся из sessionStorage (currentUser).
Если какие-то поля отсутствуют, используются fallback-значения (UNKNOWN, OPERATOR, 🛰️).

## 7. 🎨 Визуальные требования

- **Цветовая схема:** Тёмно-синий космический фон #050816, голубые акценты #4da6ff, белый текст #ffffff, оранжевое свечение для чёрной дыры.

 ## 9. 🌐 URL и маршрутизация
Так как проект является учебным и статическим (без серверной части), для локальной разработки и деплоя на GitHub Pages используются следующие адреса:

- **Local Base URL (Локальная разработка и тесты):** 
  - Карта галактик: `file:///.../cassandra//galaxy-map.html`

- **GitHub Pages URL (Публичный деплой):** 
  - Карта галактик: `https://<username>.github.io/cassandra/galaxy-map.html`

- *(Остальные страницы формируются аналогично, с обязательным суффиксом `.html`)*

> **Примечание для автоматизации:** 
> В конфигурационных файлах фреймворка (например, `config.py`) определяется базовый URL (`BASE_URL`) в зависимости от окружения. 
> Переход на конкретную страницу осуществляется путем добавления имени файла (например, `login.html`) к `BASE_URL`. Это гарантирует корректную работу тестов как на локальной машине, так и в CI/CD.
