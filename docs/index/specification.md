# 🚀 Cassandra Framework
## Техническое задание: Страница Index (Главная / Точка входа)

### 📌 Обозначения

-   **`ElementName`** *(type)* — UI-элемент с указанием типа
-   *"Text content"* — отображаемый текст на интерфейсе
-   `code` — технические термины, классы, методы
- `'/index.html'` *(url)* — адрес страницы (URL) для проверки навигации
-   ⚠️ *(decorative)* — декоративный элемент, не подлежит автоматизированному тестированию

## 1. 🎯 Назначение
Главная страница — стартовая точка входа в систему оценки колонизации. Обеспечивает первичное визуальное знакомство пользователя с проектом, демонстрацию фирменного стиля (анимация ЭКГ, космический фон, типографика) и предоставляет навигацию к точкам входа: авторизации `Log in`, и регистрации нового пользователя `Sign Up`.

## 2. 🖥️ Элементы интерфейса


### 2.1 Брендинг и текст

- **`Cassandra Logo`** *(text)* — Заголовок `CASSANDRA` в центре экрана. Состоит из двух частей:

    - **`Logo Cassan`** *(text)* — Белая часть логотипа: `CASSAN`.

    - **`Logo Dra`** *(text)* — Синяя часть логотипа: `DRA`.

- **`Project Title`** *(text)* — Подзаголовок проекта: `Planetary Habitability Assessment Project`.

- **`Title Divider`** *(decorative/css)* — Градиентная разделительная линия между заголовком и слоганом.

- **`Project Slogan`** *(text)* — Слоган проекта: `«We Find a New Home Among the Stars»`.

### 2.2 Декоративные элементы ⚠️

> **Примечание:** Элементы данного раздела являются частью визуального оформления страницы и **не подлежат автоматизированному тестированию**. Они не имеют `data-wm-id` и не включаются в CAS-сценарии.

- **`Stars Background`** *(decorative/css)* — Анимированный фон со звёздами и Млечным Путём `.stars`, `.milkyway`.

- **`Heartbeat Lines`** *(decorative/svg)* — Две `SVG`-линии (синяя и белая), имитирующие кардиограмму поверх логотипа. Анимация `drawHeartbeat` 15s, `linear`, `infinite`.

### 2.3 Основные элементы управления

- **`Log in Button`** (button/link) — Кнопка входа в систему, аналог `Uplink/Logout` по стилю. Иконка: 🔭. Состояние: Активна. При наведении (:hover) увеличивается (scale(1.15)), усиливается неоновое свечение (box-shadow).

- **`Sign Up Button`** (button/link) — Кнопка регистрации нового пользователя. Иконка:📡. Состояние: Активна. При наведении (:hover) аналогичные эффекты, как у `Log in Button`.

### 2.4 Служебные элементы

- **`Index Footer`** (text) — Футер страницы, прижатый к низу экрана.

- **`Copyright Text`** (text) — Текст `Evknopia © 2026`.

## 3. ✅ Правила состояний (State Rules)

- **Состояние `default`**

    - Все элементы видимы (opacity: 1, visibility: visible).

    - Кнопки имеют базовое неоновое свечение и cursor: pointer.

- **Состояние `hover`** (для кнопок)

    - Усиленный box-shadow (внешний и внутренний).

- **Состояние `active`** (при нажатии на кнопку)

    - Эффект лёгкого "проваливания".

## 4. ⚙️ Логика работы

⚠️ **Важно: Контекст проекта**
> Главная страница (index.html) является статической точкой входа. Проверка localStorage на этой странице не производится (она осуществляется на dashboard.html и login.html).

- **Инициализация страницы**

    - При загрузке DOM отображаются все элементы согласно CSS.

    - При обновлении страницы (F5) пользователь остаётся на index.html.

- **Навигация**

    - Клик по Data VM Button → мгновенный переход на login.html.

    - Клик по Sign Up Button → мгновенный переход на signup.html.

## 5. 🤖 Спецификация данных

- Не применимо для данной страницы (нет динамической подгрузки данных пользователя).

## 7. 🎨 Визуальные требования

- **Цветовая схема:** Тёмно-синий космический фон #050816, голубые акценты #4da6ff, белый текст #ffffff, приглушённый текст #8a94b8 (заголовок) и #6a7498 (слоган), футер #5a6488.

- **Анимации:**

    - Плавное рисование линий ЭКГ (`drawHeartbeat`, `15s`, `linear`, `infinite`).

    - Плавный переход кнопок при наведении (`transition: all 0.3s ease`).

- **Адаптивность:**

- `Desktop-first` (1024px+). Использование относительных единиц `vmin` и `vh` для масштабирования под разные разрешения экрана.

## 8. 🏷️ Спецификация data-wm-id (Ironclad Locators)

> Все интерактивные элементы должны иметь уникальный атрибут `data-wm-id` для надёжной автоматизации.

| Элемент | data-wm-id |
|---------|-----------|
| Белая часть логотипа | `logo-cassan`|
| Синяя часть логотипа | `logo-dra`|
| Заголовок проекта| `project-title`|
| Слоган проекта| `project-slogan`|
| Кнопка входа (Log in)| `btn-login`|
| Кнопка регистрации (Sign Up)| `btn-signup`|
| Копирайт в футере| `footer-copyright`|

## 9. 🌐 URL и маршрутизация
Так как проект является учебным и статическим (без серверной части), для локальной разработки и деплоя на GitHub Pages используются следующие адреса:

- **Local Base URL (Локальная разработка и тесты):**
    - Главная: `file:///.../cassandra/index.html`
    - Авторизация: `file:///.../cassandra/login.html`
    - Регистрация: `file:///.../cassandra/signup.html`

- **GitHub Pages URL (Публичный деплой):
    - Главная: `https://<username>.github.io/cassandra/index.html`
    - Авторизация: `https://<username>.github.io/cassandra/login.html`
    - Регистрация: `https://<username>.github.io/cassandra/signup.html`

- *(Остальные страницы формируются аналогично, с обязательным суффиксом `.html`)*

> **Примечание для автоматизации:** 
>В конфигурационных файлах фреймворка (например, `config.py`) определяется базовый URL (`BASE_URL`) в зависимости от окружения.
>Переход на конкретную страницу осуществляется путем добавления имени файла (например, `index.html`) к `BASE_URL`. Тесты для главной страницы не требуют предварительной настройки localStorage и должны запускаться с чистым профилем браузера.
