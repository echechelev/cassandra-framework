# 🚀 Cassandra Framework
### Техническое задание: Страница Flight Calculator (Расчёт времени полёта)

### 📌 Обозначения

-   **`ElementName`** *(type)* — UI-элемент с указанием типа
-   *"Text content"* — отображаемый текст на интерфейсе
-   `code` — технические термины, классы, методы
- `'/galaxy-map.html'` *(url)* — адрес страницы (URL) для проверки навигации
-   ⚠️ *(decorative)* — декоративный элемент, не подлежит автоматизированному тестированию

## 1. 🎯 Назначение
Страница Flight Calculator — инструмент для расчёта времени межпланетных и межзвёздных перелётов. Отображает форму выбора маршрута (система и планета отправления/прибытия), класса судна и рассчитывает время с учётом физических ограничений (траектория Гомана, манёвры разгона и торможения). Является самостоятельным модулем в экосистеме Cassandra, доступным из Dashboard.

## 2. 🖥️ Элементы интерфейса

### 2.1 Основные элементы формы

- **`Calculator Container`** (container) — Основной контейнер калькулятора. Адаптивная ширина (clamp(700px, 58vw, 950px)), максимальная высота 82vh с внутренней прокруткой.

- **`Departure Panel`** (container) — Левая панель выбора точки отправления. Содержит визуал планеты, селекты системы и планеты.

- **`Arrival Panel`** (container) — Правая панель выбора точки прибытия. Содержит визуал планеты, селекты системы и планеты.

- **`Planet Circle `** (image) — Визуальное отображение выбранной планеты (120x120px). Динамически обновляет src и alt при выборе.

- **`System Select`** (select) — Выпадающий список звёздных систем.

- **`Planet Select`** (select) — Выпадающий список планет. Зависим от выбранной системы.

- **`Ship Selection`** (radio-group) — Группа из 4 карточек выбора класса судна: Voyager (16 km/s), Parker Probe (197 km/s), Light Drive (0.1 c), Warp Drive (0.5 c).

- **`Start Button`** (button) — Кнопка запуска расчёта.


- **`Info Button`** (button) — Кнопка открытия модального окна с методологией.

- **`Clear Button`** (button) — Кнопка полного сброса формы (красная). 

- **`Dashboard Button`** (button) — Кнопка навигации (нижний левый угол). Иконка: 🕹️. Текст: DASHBOARD. Ведет на dashboard.html.

- **`Result Area`** (container) — Блок отображения результата расчёта. Появляется после 3-секундной анимации.

- **`Cassandra Logo`** (container) — Декоративный логотип ИИ в правом нижнем углу (CASSAN + DRA). Не интерактивен.

- **`Info Panel Role`** (container) — Информационная панель роли пользователя (верхний левый угол). 

- **`Info Panel User`** (container) — Информационная панель данных пользователя (верхний правый угол). 

- **`System Telemetry`** (text) — Строка телеметрии в футере. data-wm-id="system-telemetry".

### 2.2 Декоративные элементы ⚠️

>Примечание: Элементы данного раздела являются частью визуального оформления страницы и не подлежат автоматизированному тестированию.

- **`Stars Background`** *(decorative/css)* — Анимированный фон со звёздами и Млечным Путём .stars, .milkyway.

- **`Milky Way Band`** *(decorative/css)* — Светящаяся полоса Млечного Пути .milkyway .band.

### 2.3 Служебные элементы

- **`Alert Modal`** (modal) — Кастомное окно уведомлений об ошибках валидации (вместо системного alert()).

- **`Warning Modal`** Warning Modal (modal) — Красное модальное окно предупреждения о нереалистичной скорости для коротких дистанций.

- **`Info Modal`** (modal) — Модальное окно с описанием методологии расчётов.

- **`Telemetry`** *(text)* — Строка состояния системы в футере. Формат: > CASSANDRA: AURORA, FLIGHT CALCULATOR READY. SELECT ROUTE AND VESSEL CLASS... (`█`)

## 3. ✅ Правила состояний (State Rules)

- **`Состояние default`** — Все основные элементы видимы. Кнопки имеют базовое неоновое свечение.

- **`Состояние hover`** — Усиленный box-shadow, плавное увеличение масштаба (transform: scale(1.1)) для кнопок действий и карточек кораблей.

- **`Состояние calculating`** — Кнопка Start получает disabled (opacity: 0.5), появляется оверлей .calculation-overlay с анимацией радара на 3000 мс.

- **`Состояние логотипа CASSANDRA`** — Всегда статичен. pointer-events: none полностью отключает взаимодействие, opacity: 0.55.

- **`Состояние Warning`** — Если выбран Light Drive или Warp Drive, а расчётная дистанция < 1.0 св. года, вместо результата открывается красное модальное окно Warning.

## 4. ⚙️ Логика работы

> ⚠️ **Важно: Контекст проекта**
>Проект является учебным и не имеет серверной части. Данные эмулируются на стороне клиента через sessionStorage (пользователь) и глобальные объекты window.FlightCalculator в файле data.js. в файле data.js.

- **`Генерация UI`**:

    - При загрузке селекты систем заполняются из window.FlightCalculator.systems.

    - При изменении системы (change), список планет фильтруется по systemId.

    - При выборе планеты обновляются src изображения и текст описания.

- **`Формулы расчёта`**:

    - Межзвёздный (разные системы): distance = √((x2-x1)² + (y2-y1)² + (z2-z1)²) * 1.15 (+15% на разгон/торможение).

    - Внутрисистемный (одна система): distance = |orbitRadius1 - orbitRadius2| * 0.000015813 * 1.42 + 0.000019 (перевод AU в св. годы, траектория Гомана ×1.42, +~7 дней на манёвры).

    - Время: time = distance / speed.

- **`Навигация`**:

    - `Клик по Dashboard Button` → переход на `dashboard.html`.

    - `Клик по логотипу CASSANDRA` → не обрабатывается.

## 5. 🤖 Спецификация данных

Данные пользователя: sessionStorage.getItem('currentUser'). Fallback: UNKNOWN, OPERATOR.

Данные полётов: Глобальный объект window.FlightCalculator (массивы systems и planets).

- **`Константы скоростей`**:

    - voyager: 16 / 299792 (в долях c)

    - parker: 197 / 299792 (в долях c)

    - light: 0.1

    - warp: 0.5
