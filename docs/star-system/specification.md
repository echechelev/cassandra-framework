# 🚀 Cassandra Framework
## Техническое задание: Страница Star System (Звёздная система)

### 📌 Обозначения

-   **`ElementName`** *(type)* — UI-элемент с указанием типа
-   *"Text content"* — отображаемый текст на интерфейсе
-   `code` — технические термины, классы, методы
- `'/galaxy-map.html'` *(url)* — адрес страницы (URL) для проверки навигации
-   ⚠️ *(decorative)* — декоративный элемент, не подлежит автоматизированному тестированию

## 1. 🎯 Назначение
Страница Star System — детализированный просмотр выбранной звёздной системы. Отображает центральную звезду, динамически генерируемую панель доступных для исследования планет (исключая газовые гиганты), статус пользователя, а также предоставляет точки перехода к информации о звезде (star-info.html), конкретной планете (planet.html) и карте галактики. Страница является промежуточным узлом навигации между Картой Галактик и детальным изучением планет.

## 2. 🖥️ Элементы интерфейса

### 2.1 Основные элементы формы

- **`Star Container`** (link/container) — Центральный интерактивный элемент (изображение звезды). Ссылка ведёт на star-info.html?star={star_key}. Состояние: Активна. При наведении курсор меняется на pointer.

- **`Planet Bar`** (container) — Контейнер в нижней части экрана, содержащий динамически сгенерированные кнопки планет текущей системы.

- **`Planet Buttons`** (button) — Группа кнопок планет. Состояние: Активны. При наведении (:hover) увеличиваются (scale(1.15)), усиливается неоновое свечение.
Примечание: Каждая кнопка имеет уникальный data-wm-id="planet-{planet_id}-btn" (например, planet-earth-btn).

- **`Galaxy Map Button`** (button) — Кнопка возврата на карту галактики (нижний левый угол). Иконка: 🌌. Текст: Galaxy Map.

- **`Info Panel`** Role (container) — Информационная панель роли пользователя (верхний левый угол). Содержит иконку, название роли и тултип с деталями.

- **`Info Panel User`** (container) — Информационная панель данных пользователя (верхний правый угол). Содержит иконку, имя и тултип с позывным и ID.

- **`System Telemetry`** (text) — Строка телеметрии в футере, отображающая текущий статус сканирования системы.

- **`Galaxy Title`** (text) — Заголовок в верхней части экрана. Состоит из двух частей:

    - **`Title White Part`** (text) — Белая часть: STAR SYSTEM.

    - **`Title Blue Part`** (text) — Синяя часть: {Star Designation} (например, SOL, ALPHA CENTAURI).

### 2.2 Декоративные элементы ⚠️

> Примечание: Элементы данного раздела являются частью визуального оформления страницы и не подлежат автоматизированному тестированию. Они не имеют `data-wm-id` и не включаются в CAS-сценарии.

- **`Stars Background`** *(decorative/css)* — Анимированный фон со звёздами и Млечным Путём `.stars`, `.milkyway`.

- **`Milky Way Band`** *(decorative/css)* — Светящаяся полоса Млечного Пути .`milkyway .band`.

- **`Star Glow Ring`** *(decorative/css)* — Неоновое кольцо вокруг центральной звезды .star-glow-ring.

- **`Planet Icons`** *(decorative/css)* — Визуальное отображение планет (градиенты, псевдоэлементы ::before/::after для континентов, кратеров, колец), стилизуемые через CSS-переменную --p-color или уникальные классы .planet-icon.planet-{id}.

- **`Cassandra Logo`** *(decorative/css)* — Декоративный логотип ИИ в правом нижнем углу. Представляет собой круглый элемент с надписью CASSAN (белый цвет) и DRA (синий цвет #4da6ff). Элемент имеет data-wm-id="cassandra-secret-btn", но не является интерактивным: pointer-events: none, cursor: default, без hover-эффектов и кликабельности. Служит визуальным брендингом системы.

### 2.3 Служебные элементы

- **`Telemetry`** *(text)* — Строка состояния системы в футере. Отображается моноширинным шрифтом с мигающим курсором (`█`). Формат: > CASSANDRA: {CALLSIGN}, SCANNING {SYSTEM_NAME} SYSTEM... {N} PLANETS DETECTED. AWAITING SELECTION.

## 3. ✅ Правила состояний (State Rules)

- **`Состояние`** *default:* — Все элементы видимы. Кнопки имеют базовое неоновое свечение и cursor: pointer. Информационные панели и логотип CASSANDRA имеют cursor: default.

- **`Состояние hover`** *(для кнопок Planet и Galaxy Map)* — Усиленный box-shadow (внешний и внутренний), плавное увеличение масштаба (transform: scale(1.15)).

- **`Состояние active`** *(при нажатии на кнопки)* — Лёгкий эффект "проваливания" (transform: scale(0.95) или scale(1.1) в зависимости от базового ховера).

- **`Состояние логотипа CASSANDRA`** — Всегда статичен. Не реагирует на :hover, :active, :focus. pointer-events: none полностью отключает взаимодействие.

## 4. ⚙️ Логика работы

> ⚠️ **Важно: Контекст проекта**
> Данный проект является учебным и не имеет серверной части (бэкенда)**. 
> Все процессы аутентификации, хранения пользователей и передачи данных эмулируются исключительно на стороне клиента (Frontend) с использованием `sessionStorage` (для хранения активной сессии currentUser), `localStorage` (для эмуляции базы данных `registeredUsers`) и локальных конфигурационных файлов (data.js).
> В реальном продакшн-проекте эти функции выполнялись бы на сервере.

- Парсинг URL: Скрипт извлекает параметр star из URL (?star={star_key}). Если параметр отсутствует или звезда не найдена в window.starDatabase, в консоль выводится предупреждение, инициализация прерывается.

- **`Генерация UI`**:

    - Заголовок и телеметрия обновляются данными из starDatabase.

    - Панель пользователя и роли заполняется данными из currentUser.

    - Цикл forEach проходит по starData.planetData. Планеты с type === 'Gas Giant' пропускаются. Для остальных создаются кнопки с уникальными data-wm-id и CSS-классами.

- **`Навигация`**:

    - `Клик по Star Container` → переход на `star-info.html?star={star_key}`.

    - `Клик по Planet Button` → переход на `planet.html?star={star_key}&planet={planet_id}`.

    - `Клик по Galaxy Map Button` → переход на `galaxy-map.html`.

    - `Клик по логотипу CASSANDRA` — не обрабатывается (элемент декоративный).

## 5. 🤖 Спецификация данных

Данные пользователя берутся из sessionStorage (currentUser). Fallback: UNKNOWN, OPERATOR, 🛰️.
Данные звезды и планет берутся из глобального объекта window.starDatabase (файл data.js) по ключу, полученному из URL.

## 7. 🎨 Визуальные требования

- **Цветовая схема:** Тёмно-синий космический фон #050816, голубые акценты #4da6ff, белый текст #ffffff.

- **Планеты:** Используют сложные CSS-градиенты и псевдоэлементы для имитации континентов, кратеров, колец и атмосфер. Цвета задаются через CSS-переменную --p-color или переопределяются уникальными классами (например, .planet-icon.planet-earth).

- **Логотип CASSANDRA:** Состоит из двух частей — CASSAN (белый #ffffff с лёгким свечением) и DRA (синий #4da6ff с более ярким свечением). Размещён в правом нижнем углу, визуально симметричен кнопке Galaxy Map слева.

- **Анимации:** Плавное свечение (box-shadow transitions), мигающий курсор в телеметрии, плавное появление тултипов.

- **Адаптивность:** Desktop-only (1024px+). Использование относительных единиц (vmin, vh, vw) для масштабирования.

 ## 9. 🌐 URL и маршрутизация
Так как проект является учебным и статическим (без серверной части), для локальной разработки и деплоя на GitHub Pages используются следующие адреса:

- **Local Base URL (Локальная разработка и тесты):** 

    - Звёздная система: `file:///.../cassandra/star-system.html?star={star_key}`

- **GitHub Pages URL (Публичный деплой):** 

    - Звёздная система: `https://<username>.github.io/cassandra/star-system.html?star={star_key}`

> **Примечание для автоматизации:** 
>Переход на страницу требует обязательного наличия query-параметра ?star=. В конфигурационных файлах фреймворка URL формируется динамически: BASE_URL + f"star-system.html?star={star_key}".
